`Difference between Agile and Waterfall Method?`

In Agile we split our strategy into multiple sprints. And every sprint is very similar to the waterfall method. It is
used when the scope is not clear and the project is relatively complex.

The waterfall method is divided into multiple phases:

1. Requirement Gathering
2. Software Design
3. Implementation
4. Verification
5. Maintenance

If you are working on one phase you can not work on the other phase as it is sequential. It is used when the scope is
clear and the project is relatively simple.

`Difference between HTTP and HTTPS?`

Http stands for hyper-text transfer protocol and all the data sent to the server is sent in clear text and anybody in
between can read the data. Https stands for secure hyper-text transfer protocol. The data is encrypted using SSL (secure
sockets layer) or TLS (transport layer security). These are the certificates which are used to encrypt the data on
client-side and they are sent to the client through server during the beginning of communication.
